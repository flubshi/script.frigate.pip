# Security policy

## Supported versions

Security fixes are made for the latest release only.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Use GitHub's private vulnerability reporting instead:
[Report a vulnerability](https://github.com/flubshi/script.frigate.pip/security/advisories/new)

Please include:

- the add-on version and Kodi version,
- a description of the issue and its impact,
- steps to reproduce or a proof of concept, if available.

You will get an answer within 14 days. Once a fix is released, the advisory is published and you
are credited, unless you prefer otherwise.

## Scope

In scope are weaknesses in this add-on, for example in certificate handling, credential handling
or the processing of data received from Frigate or from JSON-RPC notifications.

Out of scope are weaknesses in Kodi, Frigate or Home Assistant themselves – please report those to
the respective projects – and the fact that Kodi stores add-on settings as plain text.
